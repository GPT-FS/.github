# GPT File System

**HYBRID. FLEXIBLE. AGNOSTIC. ALL-INCLUSIVE.**

Portable context and provenance, with explicit authority boundaries.

We’re building a small logical specification for carrying original content,
relationships, and inspectable records between tools. **.GPT** is the proposed
storage-neutral specification. **GPTFS** is a working reference implementation.

**[Try the live inspector](https://gpt-fs.github.io/GPT-FS/) · [Explore the repository](https://github.com/GPT-FS/GPT-FS) · [Bring a use case](https://github.com/GPT-FS/GPT-FS/discussions)**

The executable prototype supports SQLite ↔ directory snapshots, content-addressed
objects, provenance, inert plugin import, and admission/execution receipts. The
browser demo independently checks original byte hashes and history, entirely in
the tab. Its fixtures are synthetic; no account or API key is required.

A document can provide information. It cannot grant itself permission to act.
